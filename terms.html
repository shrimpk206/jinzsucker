이용약관

시행일: 2026년 11월 18일

1. 대상

이 약관은 진지서커 채널 관리 도구(이하 "도구")에 적용됩니다. 도구는 진지서커 유튜브 채널 운영자 한 명만 쓰는 내부 도구이며, 일반에 배포하거나 판매하지 않습니다.

2. YouTube 약관

도구는 YouTube API 서비스를 사용합니다. 도구를 사용하는 사람은 YouTube 서비스 약관을 따라야 하며, Google 개인정보처리방침이 함께 적용됩니다.

3. 허용되는 사용

  • 운영자 본인 채널에 직접 만든 영상을 올리고 메타데이터를 관리하는 일
  • 본인 채널 영상에 채널 이름으로 댓글을 다는 일
  • 본인 채널의 통계를 조회하는 일

다른 사람의 채널이나 데이터에 접근하는 데 쓰지 않습니다. 스팸, 조작된 참여, 저작권 침해 콘텐츠 업로드에도 쓰지 않습니다.

4. 데이터

데이터 처리 방식은 개인정보처리방침을 따릅니다.

5. 책임

도구는 있는 그대로 제공됩니다. YouTube API 정책이 바뀌면 그에 맞게 도구를 고치거나 사용을 멈춥니다.
