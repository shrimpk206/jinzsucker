채널 관리 도구에 대하여

이 사이트는 진지서커 채널이 자체적으로 쓰는 업로드·관리 도구(YouTube API 클라이언트)의 안내 페이지이기도 합니다. 이 도구는 채널 운영자 본인의 컴퓨터에서만 실행되며, 운영자 본인의 채널에 영상을 올리고 제목·설명을 관리하고, 댓글을 달고, 채널 통계를 확인하는 데만 쓰입니다. 다른 사용자의 계정에는 접근하지 않습니다.

This site also describes the in-house YouTube API client used by the 진지서커 (Jinji Sucker) channel. It runs only on the channel owner's computer and is used solely to upload and manage videos, post comments, and read analytics for the owner's own channel. It does not access any other user's account.
